PREMIUM PORTRAIT HOME — BLACK CLOVER / CAVALEIROS DO GRIMÓRIO

Mode: built-in image_gen, imagegen skill.
Assets saved in this directory:
  kingdom-portrait.png — continuous portrait kingdom illustration, without UI.
  icons-atlas.png — active standardized generated menu artwork (16 cells).
  resources-atlas.png — generated coin, diamond, essence and rarity star (4 cells).
  text-plaque.png — shared, generated empty frame for every text button.
  player-card.png — generated gold/plum player card frame; all profile data is live.

The reference image supplied by the user determines layout and visual direction.
All text, currency values, touch targets and frames are
independent Godot controls. The background does not contain functional UI.
The clarified requirement retains illustrated menu artwork and replaces emoji
and font-based pictograms with generated raster art. No text glyph is used as
a currency, power, rarity or navigation icon. Button states use plain text.
Hero illustrations and the kingdom environment are retained as game artwork.
The bottom navigation is a compact shared gold/plum dock with five main
destinations: Heroes, Bag, Formation, Evolution and Shop. Generated artwork
is retained with smaller silhouettes, subtle separators and one active marker.
Missions and Achievements remain available through the secondary Journey entry.
The app starts at scenes/premium_home.tscn in portrait 720 x 1280.
scripts/home_scene.gd composes the HUD, resource bars, quick menu, event banners,
interactive locations, bottom navigation and portrait destinations.
scripts/visuals/premium_button.gd draws ornamental, scalable gold frames.
scripts/visuals/home_effects.gd adds water shimmer, portal arcs, drifting petals,
cloud wisps and golden motes. None of these layers intercepts input.
The existing clover_idle.gd roster, save path, AFK accrual and combat are reused.
Arena, tower, clan and boss modes explicitly report unavailable rather than
pretending a server or implemented game system exists.
